四｜资金流向与投资逻辑

风险偏好维持，但对利率与能源扰动保持克制
TLT → SPY/QQQ长债偏弱时，资金更容易留在权益尤其是成长股。
IWM → QQQ利率与融资环境偏紧，市场更偏向大市值科技。
GLD → HYG若避险需求不升，部分防御资金会回流信用资产。
^VIX约15，市场波动仍低；SPY与QQQ处于高位→风险偏好尚在，回撤更多像风格切换而非系统性去杠杆→权益总体仍有支撑，但追高性价比下降优先持有强势指数与科技，等待回撤再加
TLT偏弱、媒体提到债市波动和长端压力→长端利率抬升会压制久期资产估值→成长股短线虽强，但估值敏感度上升控制QQQ追价，关注收益率回落信号
USO较高，能源成本压力仍在→高油价可能抬升通胀预期并限制利率下行→对债券和高估值权益都构成二次扰动对TLT和高久期资产保持谨慎
官方与媒体证据显示政策重心仍在贸易、财政与债市稳定→政策短期更偏托底市场情绪，而非明显收紧→风险资产不易出现快速系统性转弱维持权益中性偏多配置，等待数据确认
